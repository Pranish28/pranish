# Pranish Sris - Personal Branding Website

This is a personal website for Pranish Sris, a digital marketer based in Sainamaina municipality -4 murgiya, Rupendehi, Nepal.

## Features

- Clean and professional design
- Typing animation effect using JavaScript
- Responsive layout
- Sections for About, Services, and Contact

## How to Run

1. Open `index.html` in your web browser, or
2. Start a local server:
   - Using Python: `python -m http.server 8000`
   - Then open `http://localhost:8000` in your browser

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
